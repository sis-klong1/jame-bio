# Life With Jame_s — Link Bio

Mobile-first Liquid Glass link-in-bio page.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production files are generated in `dist/`.

## Netlify

This project is ready for Netlify.

Build command:
`npm run build`

Publish directory:
`dist`

No environment variables are required.
